Ditto Windows ARM64 3.25.146.13 - Nightly Build (beta)

Unofficial Windows ARM64 port by steathy, based on upstream Ditto build-number-146 (a80fd35).
Original Ditto by Scott Brogden, Kevin Edwards and the Ditto community.
This fork is not affiliated with or endorsed by upstream.

- Repairs inherited uninstall records that could delete settings after migration from official Ditto; removes only a known obsolete runtime file.
- Keeps two successful-installation backups and two legacy backups. Failed-attempt backups are removed after recovery is attempted, including when Setup fails. Installation consent explains this policy.
- Verifies the application before recovery restart after failed Setup. An application that fails installed-file verification stays closed, with repair instructions.
- Adds About > Manage update files with an inventory and deletion confirmation. Removing a waiting download clears its ready state and disables Install now.
- Handles read-only files, continues past cleanup failures and reports retained items. Uninstall explains when another account's update backups may remain.
- Distinguishes installed-and-verified updates with slow startup from Setup failures. Backup diagnostics report only what was actually created or retained.
- Supports cancellable update shutdown without a delayed installer launch after cancellation.
- Selects Brazilian Portuguese when its translation is packaged, with the stable Portuguese fallback otherwise.
- Expands native updater coverage to 200 checks, plus actual Options-page and isolated clipboard tests.
- Excludes internal documentation from source archives; public release notes remain with the build tooling.

Requires Windows 11 on Arm. This community build remains unsigned.
Older installed clients use their existing updater helper for the first upgrade;
these updater changes apply to updates initiated by this revision or newer.
