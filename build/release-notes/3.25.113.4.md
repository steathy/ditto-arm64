Ditto Windows ARM64 3.25.113.4 - Stable Build

Unofficial Windows ARM64 port by steathy, based on official Ditto 3.25.113.0.
Original Ditto by Scott Brogden, Kevin Edwards and the Ditto community.
This fork is not affiliated with or endorsed by upstream.

- Discards inherited uninstall records that could remove Ditto settings after migration from an official installation. Removes only a known obsolete runtime file.
- Keeps the newest two successful-installation backups and two legacy backups. Failed-attempt backups are removed after recovery; locked or inaccessible leftovers are reported.
- Adds About > Manage update files with an inventory, size and explicit deletion confirmation. Cleanup preserves live settings/history and rollback-protection records.
- Handles read-only backup files and continues past individual cleanup failures. Uninstall offers cleanup only for an identified matching desktop user with existing update files.
- Distinguishes an installed and verified update from unconfirmed application startup.
- Offers cancellation while waiting for shutdown. A withdrawn request cannot close Ditto later; an already-started shutdown is monitored for recovery without installing.
- Selects Brazilian Portuguese when that translation is packaged, otherwise retaining the stable Portuguese fallback.
- Tests representative edits on all six real editable Options pages, initialization of all eight pages, Cancel/reopen, and the cancellable shutdown protocol on an isolated desktop.
- Documents test prerequisites and rejects a missing or stale updater probe before launching the portable test.

Requires Windows 11 on Arm. This community build remains unsigned.
Updater changes take effect when an update is initiated by this revision or newer;
an older installed client still uses its existing helper for its first upgrade.
