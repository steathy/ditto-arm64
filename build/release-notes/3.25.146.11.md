# Ditto Windows ARM64 3.25.146.11 - Nightly Build (beta)

Unofficial Windows ARM64 port by [steathy](https://github.com/steathy), based on upstream build-number-146 at a80fd3536bc407cac8cce43b5682022282ace983. Original Ditto by Scott Brogden, Kevin Edwards and the Ditto community. This fork is not affiliated with or endorsed by upstream.

- Protects unsaved Options edits and refuses automatic installation until a working database is open.
- Recovers safely from backup and installation failures, including diagnostics with non-UTF-8 path text. Slow shutdown stays monitored.
- Confirms the updated database and main window are ready before showing Update successful.
- Keeps two successful-update backups and, after a successful update, two failed-attempt backups. Inactive downloads/helpers expire after seven days. Older unclassified backups remain for explicit review; interactive uninstall offers optional backup removal. Live settings and clipboard history are preserved.
- Retries transient network failures up to three attempts, discarding partial data between attempts. Hash, publisher, consent and rollback checks remain required.
- Uses the build channel for an unset beta preference while preserving saved choices. Explains when a newer nightly requires beta opt-in.
- Restores fresh-install language selection and gvim defaults without overwriting preferences; preserves previous uninstall records.
- Enforces release-text encoding and generates plain-text updater notes. Repairs draft releases using authenticated, paginated discovery.

Requires Windows 11 on Arm. This community build is unsigned; each installation requires explicit acceptance of the publisher warning. The installer, portable ZIP and complete source ZIP are provided. The source ZIP includes pinned zlib sources.

Updater changes apply when an update is initiated by this revision or newer. Older clients still use their installed helper for the first upgrade.
