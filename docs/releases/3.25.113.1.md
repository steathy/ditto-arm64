# Ditto Windows ARM64 3.25.113.1 — Stable Build

Unofficial community ARM64 port by [steathy](https://github.com/steathy), based on
the current official stable [Ditto 3.25.113.0](https://github.com/sabrogden/Ditto/releases/tag/3.25.113.0)
at commit `81a667c790f5a6c9b6b63f187eb75e79bf159670`. The final `.1` is this
fork's ARM64 revision. Ditto was created by Scott Brogden, Kevin Edwards and the
upstream community; this fork is not affiliated with or endorsed by them.

- Restores the stable application sources and bundled SQLite 3.45.2 / SQLite3
  Multiple Ciphers 1.8.4, rather than relabeling a newer nightly build.
- Retains native ARM64 support, pinned zlib 1.3.2, the fork's About page, and manual
  stable/beta update checks with download, hash verification and installation consent.
- Provides an installer, portable ZIP and complete source ZIP including zlib.
  Internal build metadata remains in Actions artifacts; checksums are below.

Targets Windows 11 on Arm. This build is unsigned; installation requires accepting
the relevant unsigned-publisher warning. Signed release support is not yet configured.
Native updater checks, isolated startup/database/ICU tests and installer compilation
run in GitHub Actions before publication. Full interactive installation and broad
clipboard/paste regression testing remain manual validation tasks.

An installed 3.25.146.x nightly is numerically newer and will not auto-downgrade to
this stable release. Switch manually if desired, after backing up settings and
clipboard history. Fresh-database tests do not establish compatibility with every
existing nightly database. Keep a backup or test the portable version separately.
