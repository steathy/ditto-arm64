Unofficial Ditto Windows ARM64 3.25.146.9 - Nightly Build (beta).

Based on upstream nightly build-number-146 at a80fd3536bc407cac8cce43b5682022282ace983.
ARM64 port maintained by steathy; original Ditto by Scott Brogden, Kevin Edwards
and the Ditto community.

- Clean release with three downloads: installer, portable ZIP and complete source ZIP.
- The source ZIP includes the pinned zlib sources; checksums are in these release notes.
- Internal build metadata stays in the GitHub Actions artifact.
- Separate stable and beta release branches and update channels.
- Clipboard functionality and the updater's verification policy are unchanged from ARM64 revision 8.

Requires Windows 11 on Arm. This community build is unsigned. Windows and Ditto's
updater may ask you to approve an unknown publisher. Full installation through the
public updater still requires end-to-end testing; keep a backup before testing upgrades.
Network/firewall blocks affecting GitHub downloads are independent of this rebuild.
