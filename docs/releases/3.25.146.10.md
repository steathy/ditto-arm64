# Ditto Windows ARM64 3.25.146.10 — Nightly Build (beta)

Unofficial ARM64 port by [steathy](https://github.com/steathy), based on upstream build-number-146 at a80fd3536bc407cac8cce43b5682022282ace983. Original Ditto by Scott Brogden, Kevin Edwards and the Ditto community. This fork is not affiliated with or endorsed by upstream.

- Adds an **Update successful** dialog after installation, installed-version verification and Ditto restart. A required Windows restart is explained in the same dialog.
- Keeps the two clickable About-page project names and removes the duplicate GitHub URL column. The original information list keeps its size.
- Fixes an invisible Windows launch-error dialog that could leave the updater waiting with Ditto closed. Failures return to recovery and are logged locally with their Windows error number.
- Preserves clipboard functionality, settings/history backups, installer hash verification and explicit consent for unsigned updates.

The completion dialog is provided by the updater that starts the installation, so updates initiated from older clients still use the older completion behavior. These builds enable the new dialog for subsequent updates.

Requires Windows 11 on Arm. This unofficial community build is unsigned; installation requires accepting the publisher warning. Releases contain an installer, portable ZIP and complete source ZIP including pinned zlib sources. Checksums appear below. Native updater and isolated startup/database/ICU tests run before publication; signed updates are not yet configured.
