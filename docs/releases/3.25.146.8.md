Unofficial Ditto Windows ARM64 3.25.146.8 - Nightly Build (beta).

Based on upstream Ditto build-number-146 at a80fd3536bc407cac8cce43b5682022282ace983.
ARM64 port maintained by steathy; original Ditto by Scott Brogden, Kevin Edwards
and the Ditto community.

- Native ARM64 application, updater helper, add-in and ICU loader.
- About-page project credits and aligned repository links, preserving the original information area.
- Manual update checks with separate stable/beta channels, release notes, download progress and SHA-256 verification.
- Explicit consent for unsigned updates; invalid signatures and incorrect hashes remain blocked.
- Installer and update helper designed to preserve existing clipboard history and settings.

This prerelease is unsigned. Windows may display an unknown-publisher or SmartScreen
warning. Only install if you trust this community build. SignPath signing is not yet
configured. Back up your clipboard database and settings before testing upgrades.
Full installation through the public update feed still needs end-to-end testing.

Requires Windows 11 on Arm. Use the setup EXE for installation or extract the entire
portable ZIP for a separate portable profile. SHA256SUMS and corresponding source
archives are included. See the original Ditto repository for core functionality.
